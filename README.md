# Курсовой проект: Приложение для анализа банковских операций

## Описание
Приложение читает Excel-файл с транзакциями и генерирует JSON-отчеты (траты по категориям, дням недели и рабочим/выходным дням), а также формирует данные для веб-страниц.

## Установка и запуск
1. Установите зависимости: `poetry install`
2. Поместите файл с транзакциями в `data/operations.xlsx`
3. Запустите главный скрипт: `poetry run python -m src.main`
4. Запустите тесты: `poetry run pytest tests`
